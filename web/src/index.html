      Game data on this device

       

      Preloaded, the game reads its tracks, cars and music from this device instead of the server: no waiting on a slow connection. Play stops the download; what came stays, and Preload fetches the rest later.

      You are playing from this computer's own server, so there is little to gain here.

      Need for Speed: Hot Pursuit 2 (2002), the PlayStation 2 version, in your browser. The game's own code is translated to C++ ahead of time and compiled to WebAssembly; WebGPU draws it and Web Audio plays it.

      The driving is the console's: the demo races recorded in the game replay with every one of their checks matching.

      Needs the latest Chrome or Edge on a computer, or the latest Chrome on an Android phone.

      The site counts visits, plays and time played to see how it is doing: no cookies, and no addresses or anything about you kept.

      Made by Vitorini: GitHub, YouTube. The source code is on GitHub: vitorinii/nfshp2-web.

      Built on ZloiKILLER's nfshp2-port-win, the static recompilation of the game and its PC runtime.

      The browser side follows th0mk's nfsu2-web, Need for Speed: Underground 2 in the browser.
